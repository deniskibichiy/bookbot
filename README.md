# bookbot
A Python-based book analysis application built using Service-Oriented Architecture (SOA), featuring independent services for book ingestion, text analysis, and report generation. Explores Python, FastAPI, REST APIs, service communication, testing, and distributed system design.

# Running Locally on Linux
1. Create and activate a dedicated Python virtual environment 
```bash
#Create
conda create -n book-bot python=3.7 
#Activate
conda activate book-bot

```
2. Install requirements using `pip`
```bash
pip install -r requirements.txt
```
3. Clone the repository to your local machine 
```bash
#Assuming you use SSh
git clone git@github.com:deniskibichiy/bookbot.git
cd book-bot
```
3. Run the app
